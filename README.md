# 🌾 Porteira Preta - Sistema de Gerenciamento Rural

Sistema web simples e funcional para gerenciamento de animais em propriedades rurais.

## 📋 Descrição

O **Porteira Preta** é um sistema de controle rural desenvolvido com HTML, CSS e JavaScript puro, sem dependências externas. Permite o cadastro, visualização e exclusão de animais, com armazenamento local no navegador.

## ✨ Funcionalidades

- 🔐 Sistema de login com credenciais fixas
- 🐄 Cadastro completo de animais (nome, tipo, idade, peso, observações)
- 📊 Contador de animais registrados
- 📋 Tabela responsiva com lista de animais
- 🗑️ Exclusão individual ou em massa
- 🌓 Modo claro/escuro
- 💾 Armazenamento local (dados permanecem após recarregar)
- 📱 Layout totalmente responsivo

## 📱 Responsividade

- 💻 Desktop

- 📱 Smartphones

## 💾 Armazenamento de Dados

Os dados são salvos localmente no navegador usando:
- **SessionStorage:** Para controle de sessão de login
- **LocalStorage:** Para armazenamento permanente de animais e preferências
